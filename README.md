# 声色 0.2.0 · 小米 14 离线测试版

录制新内容，在手机本地将音色转换为用户提供的固定参考音色，再试听或通过悬浮按钮播放。0.2.0 改用用户新提供的 MP4 中筛选的人声片段；在制作安装包时提取目标特征并固化进模型，不需要每次导入。应用没有导出功能。

本次更新排除视频片尾及非语音区间，逐段提取音色特征后平均；App 的“听参考音色”播放本次实际选用的人声。视频里若有与人声重叠的背景声音，语音区间筛选并不等于声源分离，仍应以试听为准。

## 使用

1. 安装 `timbre-xiaomi14-offline-v2.apk`，允许麦克风权限。可覆盖安装旧版本；本版沿用签名，版本号为 0.2.0。
2. 点击“开始录音”，说完后点击“结束录音”。每段最长 30 秒；建议首次先录 3～5 秒测试。
3. 点击“生成固定音色”，等待本地处理完成，再对比“原声”和“变声效果”。首次处理需要准备内置模型。
4. 点击“开启悬浮播放”，按系统提示允许显示在其他应用上层和通知。小米系统也可能在“应用设置 → 其他权限”中显示悬浮窗开关。
5. 切到需要录语音的 App，使用扬声器外放；按悬浮 `▶` 播放，按 `■` 停止。需要按住说话时，可用另一个手指点击悬浮按钮。拖动左侧 `⋮` 移动按钮，点击 `×` 关闭。

应用没有互联网权限，安装包内已包含推理模型，日常使用不需要电脑或服务器。建议预留至少 500 MB 存储空间，实际还需为系统运行保留足够内存。录音和处理结果保存在应用私有目录；重新录音替换上一段，卸载应用会清除这些内容。参考音色及模型属于安装包的一部分。

升级后，如果固定目标模型发生变化，旧的变声结果会失效，保留原录音供重新生成，避免误听上版音色。播放按钮也关闭了系统触摸提示音，以减少外放录音时混入点击声的机会。

悬浮播放通过手机扬声器发声，其他 App 是否收得到取决于其录音方式、降噪、回声消除和音频路由。蓝牙或有线耳机会改变外放效果。此版本不提供向其他 App 直接注入虚拟麦克风的能力。

## 音色与验证范围

采用 OpenVoice V2 的实际音色转换网络。处理以保留新录音的内容和节奏、接近参考音色为目标，不保证完全相同的音色或严格相同的基频。Java 音频管线保持输入输出采样数一致，但模型本身可能改变细微韵律或发音；请以实际试听为准。

电脑端已完成模型导出及真实 ONNX Runtime 推理、PyTorch/ONNX 数值对照、动态长度测试；Java 特征提取和重采样已有独立信号验证。Java 实际特征已通过真实模型全部 9 块推理检查。安装包已通过资源编译、Java/Dex 编译、签名及包内容检查。尚未在小米 14 真机上测试，不能将电脑上的耗时当作手机速度。

新目标的提取人声、片段选择记录和转换示例位于同级目录 `video-voice-reference`。语音合成源转换示例用于检验新内容通过模型的实际输出，不代表实际用户录音的相似度验收，也不能代替手机试听。

## 开发与构建

使用 Android Studio 打开本目录。要求 Java 17、Android SDK 35；Gradle Wrapper 为 8.9，Android Gradle Plugin 为 8.7.3。运行：

```powershell
.\gradlew.bat assembleDebug
```

包名 `com.example.timbre`；最低 Android 8.0；目标 Android 15；仅打包 `arm64-v8a`，适用于小米 14 的 ARM64 平台。ONNX Runtime Android 使用 1.23.2。开发阶段拉取 Gradle/Android 依赖需要联网，与安装后的离线运行无关。

`app/src/main/assets/model-config.json` 记录固定音色模型的接口、上游权重校验值和最终 ONNX 文件校验值。前处理为 22050 Hz、1024 点 periodic Hann、hop 256、两侧 reflect pad 384 的线性幅度 STFT；源音色由本地 encoder 提取，目标音色已经内置在 converter 中。

模型及依赖许可见 assets 中的许可文件；OpenVoice V2 上游为 [myshell-ai/OpenVoice](https://github.com/myshell-ai/OpenVoice) / [OpenVoiceV2](https://huggingface.co/myshell-ai/OpenVoiceV2)，ONNX Runtime 上游为 [microsoft/onnxruntime](https://github.com/microsoft/onnxruntime)。
